# 動作検証

検証日: 2026-11-16

WindowsのPython 3.14.5上で、127.0.0.1だけを使った実TCP通信により確認しました。実験室のDocker環境や帯域・遅延設定は再現していません。

`python -X utf8 -m unittest -v test_routebench` は8テストすべて成功しました。

- 8通りの経路組み合わせについて、均等分配・重み付き分配の両方でファイル全体が一致すること。
- 先頭部分だけの転送、存在範囲を超える要求の拒否。
- 共有された元ファイルを受信先として指定しても、切り詰めて破壊しないこと。
- 破損したデータのSHA-256検証が失敗し、CSVで成功扱いにならないこと。
- 分割範囲に欠落・重複がなく、指定した各経路へ正のバイト数を割り当てること。
- status/stopで比較用サービスが応答し、終了すること。
- 単独経路の校正→全組み合わせ測定→分配比の補正→各本数の候補選択がコマンドとして連携すること。
- 集計が中央値を使い、異なるファイルサイズを混ぜた候補選択や、必要な成功試行数がない選択を拒否すること。

`lab_control.py`から実験室のDockerを起動する経路は、このPCにDocker環境がないため未検証です。実験室でREADYと小さいファイルの転送を先に確認してください。

Python 3.6以降にある標準ライブラリの機能で作成していますが、実行テストを行ったPythonは上記の3.14.5です。
