# 2026-11-16 生データを伴う補助比較の再測定

過去の集計画面の元CSVは手元にないため、今回あらためて取得した別の測定記録。過去の重みが不明なので、同じ試行の再現・復元とはしない。

配布Ubuntu 18.04のDocker、Python 3.6.9、tc2の帯域と遅延を全20方向で確認。C版のA〜E測定が終わってから開始し、測定同士は重ねなかった。

事前に各単独経路を2MiBで2回ずつ校正し、その重みで20MiB（20,971,520バイト）の全8ケースを各3回測定した。**24試行成功・失敗0、全件SHA-256検証成功**。最後に残る全12個の校正・本試行出力についても、元ファイルの該当prefixとファイル全体のSHA-256が一致することを別途確認した。
