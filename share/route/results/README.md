# 保存した測定・検証データ

| ディレクトリ | 内容 |
|---|---|
| `20261116-final900` | PDFのA〜E。全条件で同じ900MiBを転送し、100秒以上・内容一致を確認する本測定 |
| `20261116-smoke` | 本測定前の16MiB・A〜E各1回。短い動作確認として本測定と区別 |
| `20261116-tests` | Ubuntuでのビルド、転送・障害・測定自動化のテスト記録 |

各測定の`run.json`に実行コマンド、日時、元ファイルのサイズ・SHA-256、計測範囲を保存する。`results.csv`は試行別記録、`summary.json`は成功した試行だけの集計。

各試行のディレクトリには、測定前後の`environment.json`（全20方向の帯域・遅延、コードハッシュ）、`links.txt`、`plan/plan.json`、生成スクリプト、サーバ・中継・クライアントの生ログを保存する。

再生成できる大容量の元ファイル・受信ファイル・実行バイナリは含めない。受信ファイルは`cmp`とMD5確認後に削除する。過去の測定値を再作成したデータではない。

解釈と条件の詳細は[検証記録](../VALIDATION_20261116.md)、実装と方針メモの対応は[対応表](../IMPLEMENTATION_STATUS.md)を参照する。
